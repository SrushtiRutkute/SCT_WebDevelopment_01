# 🚀 Responsive Landing Page

This is a fully responsive landing page with an interactive navigation menu that:
- Changes color or style when hovered.
- Stays fixed at the top of the page.
- Has a red box effect around the active menu item.

## 📌 Features
✅ Fully Responsive - Works on all screen sizes.  
✅ Interactive Navbar - Changes color on hover.  
✅ Fixed Navigation Bar - Always visible on all pages.  
✅ Smooth Scrolling - Scrolls smoothly between sections.
